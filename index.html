      Find studies
      

      Only study date, modality, description and image count are read. Patient name and ID are never requested. Tick the de-identification box in Workspace before importing; burned-in text in images must be checked by a person.
      

      Storage
        

        Images and labels live on the server computer in the data folder. Set DATA_DIR to a NAS or external disk. Automatic backup every 24 h (BACKUP_HOURS), last 7 kept (KEEP_BACKUPS).

        Connected remote systems
          

          Third-party servers
          

          Redeem the code once, then send the returned token as a Bearer header. The same token reads shared data and uploads results.
          

          

          

          Send annotated data to the main server
          

          Live edits already sync while connected. An upload adds a dated, modality-filed copy to the main server for reference and future access. It never overwrites the main labels.

          Compliance and intended use
          

          Intended use SCANTHERA prepares annotated datasets. It is not a medical device and gives no diagnosis. AI output is a suggestion that a qualified reader must review.
          

          Built in
          • Blind dual reading: Reader A and B cannot see each other's labels
          • Senior adjudication when Dice agreement is below 0.80
          • AI suggestions kept in a separate layer; accepted items are tagged with their origin in the export
          • De-identification attestation before any image is added
          • Local-only storage, delete-all control, action log
          

          Needed before real clinical or trial use
          • DICOM import with automatic tag and burned-in text removal
          • Server-side login, roles, encryption and tamper-evident audit trail
          • HIPAA / GDPR review, security audit (SOC 2 / ISO 27001), IRB or ethics approval and data-use agreements
          • Validation study of the AI per modality and task; if used for diagnosis, regulatory route (FDA, EU MDR) with quality system (ISO 13485, IEC 62304)
          • Check MedSAM license terms and weights provenance
          

          This list is a roadmap, not a guarantee of approval by any regulator, trial sponsor or ethics board.
